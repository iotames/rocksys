## 5. 交互与界面规范

| 规范项 | 说明 |
|--------|------|
| 状态色 | 启用=绿；关闭=红；切换中=橙；提示=蓝 |
| 启停开关 | 滑动开关 + 二次确认；确认文案说明影响与降级结果 |
| 操作反馈 | 右上角提示条统一走 `ui.toast` 唯一组件（见 pages.md §4.10「提示消息规范」），禁止各页面自造提示 |
| 确认弹窗 | 居中弹窗，危险操作为红色按钮 |
| 表格 | 斑马纹、悬停高亮、列头固定；空数据给出引导 |
| 加载状态 | 首次打开骨架屏；刷新时按钮旋转；请求超时弹统一 error toast（超时不算不可达，不触发顶栏横幅） |
| 空状态 | 说明原因 + 下一步操作（如"观测未开启，去开启"） |
| 数字格式 | 请求量千分位；延迟统一"毫秒"；时间统一"时:分:秒" / "年-月-日" |
| 配置输入控件 | 编辑态按配置类型自动选择控件：布尔项（`*_ENABLED` 等）=滑动开关；枚举项（`DB_DRIVER`/`ROCKSYS_LOG_LEVEL`/`SHIELD_RATE_LIMIT_BY`）=单选下拉；整数项=number 输入；规则/目标/DSN/白名单等长文本=多行 textarea；其余=文本框（类型注册表见 `webui/assets/js/state.js`） |
| 前端校验 | 保存前拦截明显非法值：整数项须非负整数、`DB_PORT` 1-65535、监听/管理地址须 `host:port`、默认后端须 `http(s)://`、IP 白名单逐项校验 IP/CIDR；校验失败红框 + 提示条，不发起请求。黑白名单新增/批量导入同样逐项校验 IP/CIDR，过期时间用日期时间选择器（前端转 RFC3339） |

**反馈闭环**：每次操作 = 确认 → 执行 → 成功 / 失败提示 → 自动刷新。绝不静默失败。

## 7. 视觉设计规范

### 7.1 主题

内置多主题切换，默认浅色（ElementUI 经典浅色）。切换入口在顶部公共横栏"主题"下拉框，选择结果保存于浏览器 `localStorage`（键 `rocksys.theme`），下次打开自动沿用；未保存时默认浅色。主题由 `html[data-theme]` 属性驱动，`webui/assets/js/theme.js` 负责持久化与绑定，`index.html` 头部的内联脚本在样式加载前应用主题以防止闪烁。

| 主题 | data-theme | 风格 |
|------|------------|------|
| 浅色（默认） | `light` | ElementUI 经典浅色（bg `#f5f7fa`、主交互 `#409eff`） |
| 深色 | `dark` | GitHub Dark 控制台风格（bg `#0d1117`、主交互 `#2f81f7`） |
| 护眼绿 | `green` | 豆沙绿护眼（bg `#c7edcc`、主交互 `#3f9d5a`） |

组件样式一律引用 `:root` 及各主题覆盖块中的语义化 CSS 变量（`--bg` / `--panel` / `--border` / `--text` / `--primary` 等），新增组件/页面时不得硬编码颜色，以保证任意主题下观感一致。深色主题色值如下：

| 色值 | 用途 |
|------|------|
| `#0d1117` | 页面背景 |
| `#161b22` | 面板 / 卡片 |
| `#1c212b` | 嵌套面板 / 表格斑马纹 |
| `#30363d` | 边框、分隔线 |
| `#e6edf3` | 主文字 |
| `#8b949e` | 次要文字 |
| `#2f81f7` | 主交互色（钢蓝） |
| `#22c55e` | 启用 / 成功 |
| `#f59e0b` | 切换中 / 警告 |
| `#ef4444` | 关闭 / 危险 / 错误 |

### 7.2 排版与间距

- 字号：正文 13px / 辅助 12px / 页面标题 16px / 指标数值 20px。
- 间距：4px 基数栅格；卡片内边距 16px；页面最大宽度 1280px 居中。
- 图标：统一简洁线形图标。

### 7.3 卡片设计

- 圆角 8px，细边框，悬停轻微上浮。
- 组件卡片：左上状态色点 + 名称，右上操作区；点击卡片主体可展开配置区。
