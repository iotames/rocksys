## 6. 实施回填区（中断现场记录）

2026-08-30 实施完成（代码改动全部落地，§4 浏览器回归留主代理）。偏差记录：

1. **waf.js 一并改动（计划外两处，均必要）**：① `TYPE_OPTIONS`（拦截明细类别筛选）排除 0——`BLOCK_TYPES` 补 `[0,'其他']` 后若不排除，拦截明细页会出现永不命中的「其他」选项（拦截事件 block_type 恒 1-10，§3.1 明确"拦截明细查询过滤保持 0-10 不变"）；② 新增 `'waf-iplist-sync-file'` action 一行——同步按钮的 data-act 委托在 waf.js 的 actions 表，不在 blacklist.js。
2. **state.js 数组顺序**：`[11,'人工收录']` 置首、`[0,'其他']` 置尾——使新增/导入下拉首选项（即默认选中项）天然为「人工收录 11」，无需额外 selected 逻辑。
3. **提交兜底未用 `|| 11` 而用区间校验**：`Number(value)` 后判断 `0-11` 范围、越界回 11——若照搬 `|| 11`，用户显式选「其他(0)」会被 `||` 短路吞成 11（0 是合法存储值，决策 1）。语义与任务要求一致（缺省 → 11）。
4. **blockTypeName(0) 现返回「其他」**（原未命中返「未知」）：0 已入枚举数组所致，符合决策 1 预期（0 显示"其他"）。
5. `go vet ./...` + `go test ./...` 全量通过（防误伤后端核实）。
